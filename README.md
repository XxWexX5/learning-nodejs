# Learning Node.js 🚀

A repository dedicated to my journey learning and deepening my knowledge of **Node.js**.

This project contains notes, experiments, exercises, and practical projects created while studying the Node.js ecosystem and backend development fundamentals.

## 🎯 Goals

The main goal of this repository is to understand **how Node.js works under the hood**, rather than relying only on frameworks and abstractions.

Throughout this journey, I will explore Node.js fundamentals by building practical applications from scratch.
